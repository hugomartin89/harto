# Changelog

## 0.7.0

- Record this framework release. A plugin can declare compatibility through 0.7.0.

## 0.6.0

- Keep real DNS and trust-store checks behind an explicit opt-in.
- Reject private host names and email addresses in the repository.

## 0.5.0

- Document how devhost changes DNS and the local trust store.

## 0.4.0

- Add devhost, which serves local processes on a base domain you choose.

## 0.3.0

- Upgrade a clean git checkout with a fast-forward.
- Check commit messages and run the suite on macOS.

## 0.2.0

- Discover, install, and remove plugins from a manifest.

## 0.1.0

- Dispatch commands and store configuration outside the repository.
- Stop setup when Homebrew or yq is missing.
